PROGRESS / METER

Verwendung

Umsetzung einer Fortschrittsanzeige. Progress wird zur Anzeige von Werten zwischen einem minimal und maximal Wert verwendet.

Attribute

Attribut Werte Beschreibung
max Ganzzahliger Wert Definiert den Wert der Fertigstellung.
value Ganzzahliger Wert Definiert den aktuellen Wert.

Code

<progress max="5" value="2">Schritt 2 von 5</progress>
<meter value="0.85">25%</meter>

Beispiel

Schritt 2 von 5
85%
