VIDEO

Verwendung

Einbinden eines Videos in das Dokument.

Attribute

Attribut Werte Beschreibung
src Pfad zur Quelle
controls Anzeige der Steuerelemente
preload Mediainhalt vorladen
autoplay Medienwiedergabe automatisch starten
loop Wiedergabe wiederholen.
width Zahl Breite
height Zahl Höhe
media handheld, all, ...
type video/mp4, video/ogg, ...
codecs theora, vorbis, ...

Code

Einfach:
<video src=".." width="320" heihgt="240" controls>
<a href="..">Video ansehen.</a>
</video>

Erweitert:
<video width="320" heihgt="240" controls>
<source src="..." type="video/mp4">
<source src="..." type="video/ogg">
<p>
<a href="...">Video ansehen.</a>
</p>
</video>
