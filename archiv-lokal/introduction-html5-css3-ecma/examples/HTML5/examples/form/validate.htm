Validierung von Eingabe-Elementen

Eingabe-Elemente ohne Validierung:
hidden
submit
image
reset
object

Eingabe-Elemente mit eingebauter Syntax-Regel:
email
url
number
range

Eingabe-Elemente ohne eingebauter Syntax-Regel:
text
textarea
search
telephone
password
datetime, date, time, datetime-local, week, month
checkbox
color
radio

Zum unterdrücken der automatischen Validierung das novalidate Atrribute am form Element anbringen.

Formular-Elemente die validiert werden sollen müssen folgende Bediengungen erfüllen:
  • kein disabled oder readonly Attribute
  • muss das name Attribute tragen
  • muss in einem form Element stehen oder form Attribute tragen

Code

<form id="demo2">
<p><label>Name: <input name=name required></label></p>
<p><label>E-mail: <input name=email type=email required></label></p>
<p><label>URL: <input name=url type=url required></label></p>
<p><label>Comment: <textarea name=comment required></textarea></label></p>
<p><input type=submit value=Senden></p>
</form>
